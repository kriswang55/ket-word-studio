# 項目說明

[English](../en/project-overview.md) | [简体中文](../zh-CN/project-overview.md) | **繁体中文**

KET Word Studio 是一個詞彙學習技術演示項目，面向課程設計展示和技術評審。目標是讓訪問者在無需登錄的條件下，檢查從詞彙維護、抽題、作答、判分到錯詞溫習與統計的完整流程。

## 場景與範圍

學生頁面提供練習、詞彙檢索、錯題溫習和成績分析。教師頁面提供詞庫管理與練習記錄查看。兩種模式使用同一份當前演示數據，並通過左側按鈕切換。

在線網站採用靜態部署；每名評審在自己的瀏覽器裏獨立操作，互不影響。桌面版使用 Qt 原生控件與 SQLite，用於展示 Python 應用組織、界面事件與事務持久化。

## 核心功能

| 模塊 | 行為 |
| --- | --- |
| 詞庫 | 178 個初始詞條、19 個主題，支持新增、編輯、停用和別名 |
| 抽題 | 按主題或全部詞彙取樣，同次練習不重複，數量不足按實際詞數出題 |
| 判分 | NFKC 歸一化、大小寫不敏感、空白合併、可接受答案匹配 |
| 進度 | 每次提交儲存答案，重開後繼續未完成練習 |
| 錯詞 | 最近一次已完成練習答錯的詞進入溫習，後續答對後移出 |
| 統計 | 練習次數、總題數、加權正確率、平均正確率、最高 / 最低值、趨勢 |
| 導出 | JSON 含逐題明細；CSV 含練習彙總，可供表格軟件讀取 |
| 演示恢復 | 清除新增數據並恢復詞庫和 3 條示例成績 |

初始示例成績的正確率分別為 40%、60%、80%，每次 5 題。頁面與導出文件均標註來源，不作為真實學習效果的證據。

## 設計取捨

無需賬户降低評審進入成本；本地數據隔離避免訪客互相覆蓋內容。瀏覽器版不需要持續運行 Python 服務器，可直接託管於 GitHub Pages。桌面版獨立運行並保留同樣的練習規則。

本項目未實現用户認證、跨設備同步、真實班級管理、雲數據庫或 AI 語義判分。角色切換用於展示界面和功能，不構成安全邊界。

## 語言切換

網站、Qt 桌面版與文檔均提供 **English / 简体中文 / 繁体中文**，首次啓動默認英語。點擊側邊欄的三個語言按鈕即可切換，當前語言會高亮；網站記住當前瀏覽器的選擇，Qt 在數據庫旁的 `preferences.json` 中儲存選擇。文檔頂部的鏈接會切換到同一篇文檔。

切換語言保留當前身份、練習進度、未提交的答案和判分結果。導航、內置主題、提示與 CSV 表頭隨語言變化，JSON 字段名保持穩定。這是根據中文釋義填寫英文的練習，繁體界面顯示內置釋義的繁體版本；教師自行輸入的內容保持原樣。

語言代碼統一為 `en`、`zh-CN`、`zh-HK`。
