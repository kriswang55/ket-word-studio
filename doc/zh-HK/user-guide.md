# 使用說明

[English](../en/user-guide.md) | [简体中文](../zh-CN/user-guide.md) | **繁体中文**

## 進入與切換

網站打開即進入學生頁面；桌面程序啓動後同樣直接可用。點擊“教師頁面”或桌面版“切換到教師頁面”查看教師功能，返回學生頁面繼續練習。無需賬號或密碼。

學生導航包括學習概覽、詞彙練習、詞彙手冊、錯題溫習、學習記錄。教師導航僅有管理概覽、詞庫管理、練習記錄。

## 語言切換

網站、Qt 桌面版與文檔均提供 **English / 简体中文 / 繁体中文**，首次啓動默認英語。點擊側邊欄的三個語言按鈕即可切換，當前語言會高亮；網站記住當前瀏覽器的選擇，Qt 在數據庫旁的 `preferences.json` 中儲存選擇。文檔頂部的鏈接會切換到同一篇文檔。

切換語言保留當前身份、練習進度、未提交的答案和判分結果。導航、內置主題、提示與 CSV 表頭隨語言變化，JSON 字段名保持穩定。這是根據中文釋義填寫英文的練習，繁體界面顯示內置釋義的繁體版本；教師自行輸入的內容保持原樣。

## 練習

1. 打開詞彙練習，選擇隨機練習或錯題溫習。
2. 設置題數和主題。程序只會使用啓用的詞彙，最多取當前可用數量。
3. 根據中文輸入英文，點擊提交答案；也可按 Enter 提交。跳過按錯誤答案處理。
4. 查看當前判分後進入下一題；末題提交後查看成績。

答案忽略大小寫、首尾和重複空白、全角字符差異。不會自動糾正拼寫，不支持未列入別名的同義表達。已提交答案不能修改。

離開頁面或關閉程序後，可以繼續未完成的練習。主動結束的未完成練習不進入成績統計或錯題本。

## 教師管理詞彙

在詞庫管理中新增英文、中文釋義、主題，可用英文分號填寫多個可接受答案。主題可選擇已有內容，也可直接新建。英文詞條不允許重複，大小寫和全角差異也視作重複。

編輯詞條時取消“啓用詞彙”，即可從後續新練習與學生詞彙手冊中隱藏；重新啓用後恢復。正在進行的練習和歷史成績仍使用開始練習時儲存的題目內容。

## 查看與導出

學習記錄 / 練習記錄支持查看每道題的中文、正確答案、提交答案及結果。JSON 導出包含逐題詳情；CSV 導出包含彙總，並對以公式字符開頭的文本加保護前綴。

平均正確率是每次練習正確率的算術平均，累計正確率為總正確題數除以總作答題數。例如 1 題全對和 3 題全錯，平均正確率是 50%，累計正確率是 25%。

## 數據與重置

網站使用瀏覽器 localStorage，關閉後通常保留；清理網站數據或使用隱私窗口可能使數據消失。不同瀏覽器、網址來源與端口的數據互相獨立。多個訪客不會互相看到操作結果，同一瀏覽器標籤頁會提示數據更新；請順序演示，避免多個頁面同時修改。

桌面默認數據庫：Windows 為 `%LOCALAPPDATA%\KETWordStudio\demo.sqlite3`；Mac 為 `~/Library/Application Support/KETWordStudio/demo.sqlite3`；Linux 為 `$XDG_DATA_HOME/KETWordStudio/demo.sqlite3`，未設置時使用 `~/.local/share`。桌面支持 `--data-dir 路徑` 指定隔離數據目錄。

點擊“重置演示數據”並確認後，新增詞彙和練習會被刪除，恢復初始詞庫與 3 條示例成績。重置隻影響當前瀏覽器或當前桌面數據目錄。導出記錄不等於完整備份，項目沒有導入恢復功能。

## 常見問題

- 網站不能直接雙擊 HTML 運行：模塊和詞庫讀取需要 HTTP / HTTPS，請使用在線網址或本地預覽命令。
- 本地網站無法啓動：端口 8765 可能被佔用，關閉已有預覽或使用 `--port 8766`。
- 網站提示無法儲存：檢查瀏覽器是否禁止本地存儲或空間是否已滿。
- 錯題模式沒有題目：選定主題中可能沒有待溫習的啓用詞彙，可切換全部主題。
- 在線與桌面數據不同：兩端是獨立演示，未提供同步。
