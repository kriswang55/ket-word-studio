# 项目说明

[English](../en/project-overview.md) | **简体中文** | [繁体中文](../zh-HK/project-overview.md)

KET Word Studio 是一个词汇学习技术演示项目，面向课程设计展示和技术评审。目标是让访问者在无需登录的条件下，检查从词汇维护、抽题、作答、判分到错词复习与统计的完整流程。

## 场景与范围

学生页面提供练习、词汇检索、错题复习和成绩分析。教师页面提供词库管理与练习记录查看。两种模式使用同一份当前演示数据，并通过左侧按钮切换。

在线网站采用静态部署；每名评审在自己的浏览器里独立操作，互不影响。桌面版使用 Qt 原生控件与 SQLite，用于展示 Python 应用组织、界面事件与事务持久化。

## 核心功能

| 模块 | 行为 |
| --- | --- |
| 词库 | 178 个初始词条、19 个主题，支持添加、编辑、停用和别名 |
| 抽题 | 按主题或全部词汇取样，同次练习不重复，数量不足按实际词数出题 |
| 判分 | NFKC 归一化、大小写不敏感、空白合并、可接受答案匹配 |
| 进度 | 每次提交保存答案，重开后继续未完成练习 |
| 错词 | 最近一次已完成练习答错的词进入复习，后续答对后移出 |
| 统计 | 练习次数、总题数、加权正确率、平均正确率、最高 / 最低值、趋势 |
| 导出 | JSON 含逐题明细；CSV 含练习汇总，可供表格软件读取 |
| 演示恢复 | 清除新增数据并恢复词库和 3 条示例成绩 |

初始示例成绩的正确率分别为 40%、60%、80%，每次 5 题。页面与导出文件均标注来源，不作为真实学习效果的证据。

## 设计取舍

无需账户降低评审进入成本；本地数据隔离避免访客互相覆盖内容。浏览器版不需要持续运行 Python 服务器，可直接托管于 GitHub Pages。桌面版独立运行并保留同样的练习规则。

本项目未实现用户认证、跨设备同步、真实班级管理、云数据库或 AI 语义判分。角色切换用于展示界面和功能，不构成安全边界。

## 语言切换

网站、Qt 桌面版与文档均提供 **English / 简体中文 / 繁体中文**，首次启动默认英语。点击侧边栏的三个语言按钮即可切换，当前语言会高亮；网站记住当前浏览器的选择，Qt 在数据库旁的 `preferences.json` 中保存选择。文档顶部的链接会切换到同一篇文档。

切换语言保留当前身份、练习进度、未提交的答案和判分结果。导航、内置主题、提示与 CSV 表头随语言变化，JSON 字段名保持稳定。这是根据中文释义填写英文的练习，繁体界面显示内置释义的繁体版本；教师自行输入的内容保持原样。

语言代码统一为 `en`、`zh-CN`、`zh-HK`。
