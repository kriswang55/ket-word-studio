# 使用说明

[English](../en/user-guide.md) | **简体中文** | [繁体中文](../zh-HK/user-guide.md)

## 进入与切换

网站打开即进入学生页面；桌面程序启动后同样直接可用。点击“教师页面”或桌面版“切换到教师页面”查看教师功能，返回学生页面继续练习。无需账号或密码。

学生导航包括学习概览、单词练习、词汇手册、错题复习、学习记录。教师导航仅有管理概览、词库管理、练习记录。

## 语言切换

网站、Qt 桌面版与文档均提供 **English / 简体中文 / 繁体中文**，首次启动默认英语。点击侧边栏的三个语言按钮即可切换，当前语言会高亮；网站记住当前浏览器的选择，Qt 在数据库旁的 `preferences.json` 中保存选择。文档顶部的链接会切换到同一篇文档。

切换语言保留当前身份、练习进度、未提交的答案和判分结果。导航、内置主题、提示与 CSV 表头随语言变化，JSON 字段名保持稳定。这是根据中文释义填写英文的练习，繁体界面显示内置释义的繁体版本；教师自行输入的内容保持原样。

## 练习

1. 打开单词练习，选择随机练习或错题复习。
2. 设置题数和主题。程序只会使用启用的词汇，最多取当前可用数量。
3. 根据中文输入英文，点击提交答案；也可按 Enter 提交。跳过按错误答案处理。
4. 查看当前判分后进入下一题；末题提交后查看成绩。

答案忽略大小写、首尾和重复空白、全角字符差异。不会自动纠正拼写，不支持未列入别名的同义表达。已提交答案不能修改。

离开页面或关闭程序后，可以继续未完成的练习。主动结束的未完成练习不进入成绩统计或错题本。

## 教师管理词汇

在词库管理中添加英文、中文释义、主题，可用英文分号填写多个可接受答案。主题可选择已有内容，也可直接新建。英文词条不允许重复，大小写和全角差异也视作重复。

编辑词条时取消“启用词汇”，即可从后续新练习与学生词汇手册中隐藏；重新启用后恢复。正在进行的练习和历史成绩仍使用开始练习时保存的题目内容。

## 查看与导出

学习记录 / 练习记录支持查看每道题的中文、正确答案、提交答案及结果。JSON 导出包含逐题详情；CSV 导出包含汇总，并对以公式字符开头的文本加保护前缀。

平均正确率是每次练习正确率的算术平均，累计正确率为总正确题数除以总作答题数。例如 1 题全对和 3 题全错，平均正确率是 50%，累计正确率是 25%。

## 数据与重置

网站使用浏览器 localStorage，关闭后通常保留；清理网站数据或使用隐私窗口可能使数据消失。不同浏览器、网址来源与端口的数据互相独立。多个访客不会互相看到操作结果，同一浏览器标签页会提示数据更新；请顺序演示，避免多个页面同时修改。

桌面默认数据库：Windows 为 `%LOCALAPPDATA%\KETWordStudio\demo.sqlite3`；Mac 为 `~/Library/Application Support/KETWordStudio/demo.sqlite3`；Linux 为 `$XDG_DATA_HOME/KETWordStudio/demo.sqlite3`，未设置时使用 `~/.local/share`。桌面支持 `--data-dir 路径` 指定隔离数据目录。

点击“重置演示数据”并确认后，新增词汇和练习会被删除，恢复初始词库与 3 条示例成绩。重置只影响当前浏览器或当前桌面数据目录。导出记录不等于完整备份，项目没有导入恢复功能。

## 常见问题

- 网站不能直接双击 HTML 运行：模块和词库读取需要 HTTP / HTTPS，请使用在线网址或本地预览命令。
- 本地网站无法启动：端口 8765 可能被占用，关闭已有预览或使用 `--port 8766`。
- 网站提示无法保存：检查浏览器是否禁止本地存储或空间是否已满。
- 错题模式没有题目：选定主题中可能没有待复习的启用词汇，可切换全部主题。
- 在线与桌面数据不同：两端是独立演示，未提供同步。
